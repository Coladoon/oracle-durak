# Версия 2 — упрощённая консоль

Полная версия проекта с интерфейсом, выбранным Михаилом:

- `V_GAME_CONSOLE` показывает состояние одной строкой;
- `V_LOG_TEXT` показывает понятный журнал;
- `DURAK_CONSOLE.PLAY` принимает команды `ХОД`, `БИТО`, `ПОДКИНУТЬ`,
  `ПЕРЕВОД`, `ВЗЯТЬ`, `ПАС`, `БОТЫ`;
- команда может состоять только из кода карты;
- результат возвращается через `:message`.

Установка: `@install.sql`, полная проверка: `@tests/run_all.sql`.
