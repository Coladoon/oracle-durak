# «Дурак» только на Oracle

Серверная реализация карточной игры «Дурак» на Oracle SQL и PL/SQL. Пользовательский интерфейс проекта — SQL-клиент, представления и текстовые сообщения `DBMS_OUTPUT`.

## Текущее состояние

Реализовано серверное игровое ядро и расширенный функциональный инкремент:

- повторяемая установка и удаление объектов;
- нормализованная схема партий, игроков, карт, раундов, событий, Daily и турниров;
- справочник из 52 карт с поддержкой выборки колоды 36 карт;
- детерминированные SHA-256-функции для seed и порядка колоды;
- базовые правила сравнения карт и расчёта лимитов;
- серверный игровой автомат: лобби, раздача, атака, защита, подбрасывание,
  перевод, пас, взятие, отбой, добор и завершение партии;
- публичный пакет `DURAK_API` с текстовыми результатами операций;
- таймеры хода и простоя через `DBMS_SCHEDULER`;
- Daily-партии с единым seed по дате и автоматической записью результатов;
- пошаговый реплей завершённых партий и игровая аналитика;
- PvE-боты уровней `EASY`, `NORMAL` и `HARD`, ходы которых выполняются внутри Oracle;
- круговые турниры и олимпийские сетки на 2–16 участников с автоматическим
  подсчётом очков, проходами без соперника и определением чемпиона;
- защищённые представления требуемых типов;
- SQL-тесты справочника, seed, правил боя, игрового цикла, Daily, ботов и турниров.

## Требования

- Oracle Database 19c или новее;
- SQL*Plus, SQLcl либо совместимый клиент;
- права на создание таблиц, последовательностей, пакетов и представлений;
- право `CREATE JOB` для фонового обработчика таймеров.

Все SQL-файлы проекта должны сохраняться в UTF-8.

## Установка

Подключитесь к целевой схеме и выполните:

```sql
@install.sql
```

Установка не удаляет существующие данные. Для явной полной переустановки:

```sql
@reinstall.sql
```

## Тесты

После установки выполните:

```sql
@tests/run_all.sql
```

Тесты завершают сценарий ошибкой Oracle, если хотя бы одна проверка не прошла.

## Структура

- `sql/` — схема, пакеты, представления и служебные сценарии;
- `tests/` — автоматические SQL/PLSQL-проверки;
- `tests/concurrency/` — ручная проверка конфликта двух Oracle-сессий;
- `demo/` — демонстрационные партии;
- `admin/` — выдача минимальных прав Oracle-пользователям;
- `docs/` — архитектура и статус реализации.

Пошаговый запуск из двух терминалов, партия с ботом и турнир описаны в
`docs/USAGE.md`.
