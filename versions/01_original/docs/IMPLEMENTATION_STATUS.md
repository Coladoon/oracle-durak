## Принятые проектные решения

- Источник истины — только таблицы Oracle.
- Карта партии хранится одной строкой и имеет ровно одну текущую зону.
- Публичные пользователи не получают права прямого DML на игровые таблицы.
- Детерминированное перемешивание строится на `STANDARD_HASH(..., 'SHA256')`.
- Значения `BOOLEAN` в таблицах представлены `CHAR(1)` со значениями `Y/N`.
- Время хранится как `TIMESTAMP WITH TIME ZONE`.
