# Статус реализации

## Итог

Основная редакция покрывает только минимальный и хороший уровни задания.
Контрольная установка выполнена в отдельной схеме Oracle Free. Результат
автоматического прогона: **78 успешно, 0 ошибок**. Конкурентный сценарий из двух
сеансов также пройден.

## Минимальный уровень

- [x] 2 игрока, подкидной вариант, колода 36.
- [x] Раздача по 6 карт и определение козыря.
- [x] Первый атакующий определяется по младшему розданному козырю.
- [x] Атака и защита одной или несколькими картами.
- [x] Правила покрытия по масти и козырю.
- [x] Подбрасывание только достоинств, присутствующих на столе.
- [x] Лимит пар и ограничение по руке защитника.
- [x] Добор до 6 карт и отсутствие добора после закрытия талона.
- [x] История раундов и событий.
- [x] Табло побед, поражений, средней длительности и числа раундов.
- [x] Воспроизводимый seed и полный порядок колоды.

## Хороший уровень

- [x] От 2 до 6 игроков; вышедшие пропускаются.
- [x] Колода 36 по умолчанию или 52.
- [x] Подкидной вариант по умолчанию или переводной.
- [x] Первый ход по младшему козырю или случайно по seed.
- [x] Своя рука открыта владельцу; чужие руки представлены счётчиками.
- [x] Стол, козырь, талон и количество карт видны всем участникам.
- [x] Таймер хода выполняет авто-действие и пишет причину в протокол.
- [x] Длительный простой завершает партию корректно.
- [x] Daily формирует одинаковый seed по дате и версии правил.
- [x] `V_DAILY_RESULTS` строит табло дня.
- [x] `V_REPLAY` воспроизводит события и перемещения карт по шагам.

## Надёжность

- [x] Одна активная партия на одного Oracle-пользователя.
- [x] Игровые изменения выполняются атомарно.
- [x] Конфликт двух сеансов отклоняется кодом `-20702`.
- [x] Все устанавливаемые пакеты и представления имеют статус `VALID`.
- [x] Фоновое задание `DURAK_MAINTENANCE_JOB` включено.

## Исключено из основной редакции

- боты Easy, Normal и Hard;
- турниры;
- расширенная аналитика уровня «отлично»;
- настраиваемые домашние правила уровня «отлично».

Эти модули не устанавливаются и не проверяются. Их прежняя версия сохранена
только в архивном каталоге `versions/02_human_console`.
