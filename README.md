# Дурак только на Oracle

Серверная реализация карточной игры «Дурак» на Oracle SQL и PL/SQL.
Объём реализации соответствует минимальному и хорошему уровням технического
задания. Боты, турниры и расширенная аналитика в основную установку не входят.

## Реализовано

- подкидной и переводной варианты;
- партии от 2 до 6 игроков с пропуском вышедших;
- колоды 36 и 52 карты, раздача по 6 карт и открытый козырь;
- первый ход по младшему козырю либо детерминированно по seed;
- атака, защита, подбрасывание, перевод, пас, взятие, отбой и добор;
- лимиты стола по размеру колоды и числу карт защитника;
- детерминированный порядок колоды;
- таймеры хода и простоя с записью причин авто-действий;
- Daily-раскладка и дневное табло;
- пошаговый реплей;
- история раундов и общее табло побед, поражений и средней длительности;
- маскирование чужих рук в пользовательских представлениях;
- защита от второй активной партии пользователя и конфликтующих действий;
- текстовая консоль с русскими командами.

## Требования

- Oracle Database 19c или новее;
- SQL Developer, SQL*Plus, SQLcl либо совместимый клиент;
- права на создание таблиц, последовательностей, пакетов и представлений;
- право `CREATE JOB` для фонового обработчика таймеров.

Все SQL-файлы должны сохраняться в UTF-8.

## Установка

В схеме-владельце выполните:

```sql
@install.sql
```

Для полной переустановки с удалением старых игровых данных:

```sql
@reinstall.sql
```

Полное руководство по Docker, SQL Developer, созданию пользователей, ручной
игре, Daily, реплею и тестам: [`docs/PROJECT_GUIDE.md`](docs/PROJECT_GUIDE.md).

Иллюстрированное руководство по установке и использованию:

- [`Руководство Word`](docs/Руководство_по_запуску_и_игре_Дурак_Oracle.docx);
- [`Руководство PDF`](docs/Руководство_по_запуску_и_игре_Дурак_Oracle.pdf).

## Проверка

```sql
@tests/run_all.sql
```

При проверке на Oracle Free получено **78 успешных проверок, 0 ошибок**.
Двухсеансовый тест подтвердил отказ `-20702` при одновременной попытке
изменить одну партию.

## Структура

- `sql/` — схема, правила, игровой автомат, API, таймеры и представления;
- `tests/` — автоматические проверки требований;
- `tests/concurrency/` — сценарий проверки двух одновременных сеансов;
- `demo/` — сценарии создания, подключения, игры и Daily;
- `admin/` — выдача минимальных прав игрокам;
- `docs/` — инструкция и матрица соответствия требованиям;
- `versions/02_human_console/` — сохранённая расширенная редакция с функциями
  уровня «отлично», не входящая в основную установку.
