# Проверка конкурентного доступа

Сценарий подтверждает, что две Oracle-сессии не могут одновременно изменить
одну партию.

1. В первом окне SQL Developer выполните `01_prepare.sql` и запишите выведенные
   `GAME_ID` и `PLAYER_ID`.
2. В том же окне выполните `02_session_a_lock.sql`, укажите `GAME_ID` и не
   нажимайте Enter на строке `PAUSE`.
3. Во втором окне выполните `03_session_b_action.sql`, указав тот же `GAME_ID`
   и выведенный `PLAYER_ID`.
4. Второе окно должно вывести `[OK] Конфликт корректно отклонён кодом -20702`.
5. Вернитесь в первое окно и нажмите Enter — блокировка будет снята откатом.

Тестовые строки имеют имена `Concurrency Test ...` и не затрагивают обычные
партии.
